Review the selected code or recent changes for:

- **Bugs and edge cases**: Logic errors, null/undefined handling, off-by-one errors
- **Security issues**: Injection vulnerabilities, exposed secrets, unsafe deserialization, improper input validation
- **Performance**: Unnecessary loops, memory leaks, inefficient queries
- **Readability**: Overly complex logic, misleading variable names, missing error handling

Be concise and actionable. For each issue, provide the line reference and a suggested fix.
